# Token Forge 设计令牌工作台

基于 SolidJS、TypeScript、Vite、Kobalte、Tailwind CSS、Solid Router 和 Style Dictionary 的本地设计令牌工作台。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
```

生产构建：

```bash
corepack pnpm build
corepack pnpm tokens:build
```

## 已实现功能

- 管理颜色、字号、间距、圆角、阴影和动效时长令牌。
- 多套主题切换、复制和本地持久化。
- 编辑令牌后组件预览实时刷新。
- 自动计算正文与关键颜色组合的 WCAG 对比度等级。
- 保存修改快照并比较两次修改之间的差异。
- 导入 JSON，导出 Style Dictionary JSON、CSS Variables 和 Sass Variables。
- `tokens:build` 使用 Style Dictionary 输出 CSS、SCSS 和扁平 JSON。

## 令牌引用与对账流程

令牌值可写 `{color.brand.primary}` 形式的引用，把基础值、别名和组件变体串成依赖链：

- **失效重算**：基础值改动后，依赖它的别名与组件变体立即按新值重算，编辑器、组件预览、版本差异和导出统一使用解析后的最新值，不会停在编辑前的旧值。
- **显式覆盖**：把别名改成字面值即记为显式覆盖。基础值再变时覆盖令牌保留原值，并标为“待复核”进入复核队列；维护员可逐枚或批量“保留覆盖 / 恢复跟随”。
- **引用检查**：引用断裂（目标不存在）或成环时，导出停在写盘前，并指出卡在哪枚令牌、断在哪条引用或环路径。
- **发布导出包**：发布时解析全部令牌并计算包指纹（FNV-1a），生成带版本号的导出包，可下载 CSS / Sass / JSON。写盘失败保留上一版发布，失败记录可重试（可勾选“模拟下次写盘失败”验证）。
- **产品回执对账**：产品装包后回报包指纹，与当前导出包逐台核对；指纹对不上即进偏差清单，该产品不计入同步完成。产品重新回报匹配指纹后偏差自动结清，全部产品指纹一致才算同步完成。
- **断点续作**：主题、快照、导出包、回执与偏差清单均持久化在本地，重开工作台可接着复核与发布。
